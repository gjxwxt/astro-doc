# 品牌：半亩 / Bothy

## 名字层级

| 名称 | 用途 |
| --- | --- |
| **半亩** | 中文产品名 |
| **Bothy** | 英文产品名 |
| **Josh** | 作者本人；不再作为产品名 |

产品名和作者名分开。公开页面可以出现「半亩」，但不要写「Josh 的产品」；Josh 只出现在关于、签名、作者信息里。

## 一句话

中文：

> 半亩——留一点自己的东西。

英文：

> Bothy — a quiet place for what you keep.

## 使用方式

- 中文界面主品牌：`半亩`
- 英文语境主品牌：`Bothy`
- 私有工作台：`半亩`，必要时加小号 `Bothy`
- 采集插件：`半亩 Inbox`、`半亩媒体`、`半亩 Capture`
- 不要写：`Josh Inbox`、`Josh AI`、`半亩 AI`
- 内部代码、插件 ID、Cookie、日志、服务名继续保持 `josh-*`，不要为了品牌改名破坏兼容性

## 视觉

- 中文主字：`半亩`
- 英文小字：`Bothy`，大写字母距略宽
- 对外标题：`半亩 · 文档、笔记与工具`
- 页脚署名：`© 年份 Josh`，不写 `© 半亩`

## 语气

安静、具体、克制。少用「智能」「第二大脑」「革命性」；多描述实际动作：收进来、整理、找到、写出去。
