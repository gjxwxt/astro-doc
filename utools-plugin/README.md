# Josh Capture（uTools 插件）

全局快速收藏：从任意桌面应用把选中文字、剪贴板图片、链接或本地图片存进 Josh Inbox。

浏览器里的网页上下文仍用 Chrome 扩展；uTools 补的是微信、飞书、PDF、IDE 这类没有扩展的场景。

## 开发/安装

1. 打开 uTools → 设置 → 开发者 → 新建插件
2. 选择 `utools-plugin/josh-capture/plugin.json`
3. 在 uTools 里给「josh / 收藏」设置一个全局快捷键

不需要构建，目录里就是最终文件。

## 设置

首次打开点右上角「设置」：

- **门户地址**：`http://127.0.0.1:4400` 或云服务器地址
- **图片公开地址**：写进图片碎片的绝对前缀；留空则用门户地址
- **私有 API Token**：服务端 `.env` 的 `PRIVATE_API_TOKEN`

图片公开地址必须是 Obsidian/浏览器能访问的地址；本机测试可以用 `http://127.0.0.1:4400`。

## 超级右键（划词）

选中文字后触发 uTools 超级右键/超级面板，会看到两个入口：

- **收藏到 Josh**：打开快速收藏窗口，文字已填好，可补标签/备注再保存
- **秒存到 Josh**：不打开编辑，直接存入 Inbox，完成后通知并关闭

它们由 `plugin.json` 里的 `type: "over"` 命令提供，和翻译、添加至备忘同一套机制。

> 修改 `plugin.json` 后，需要在 uTools 开发者工具里重新加载/重装一次插件，超级右键才会出现新入口。

## 能做什么

- 选中文字 → 超级右键「收藏到 Josh」→ 补标签/备注 → 存入为引用
- 选中文字 → 超级右键「秒存到 Josh」→ 直接入库
- 剪贴板图片 → 读图片/⌘V/拖入 → 上传 → 图片碎片
- 图片 URL → 自动存为图片碎片
- 普通 URL → 保存链接（带预览）
- 本地图片路径 → 通过 preload 读取并上传
- 备注、标签、来源 URL
- `⌘/Ctrl + Enter` 保存

## 限制

- 拿不到浏览器页面标题/上下文；网页请用 Chrome 扩展
- 远程图片没有扩展名（如 `?id=123`）不会自动识别为图片
- 单张上限 20MB；支持 PNG/JPEG/WebP/GIF/AVIF，不支持 SVG
- 剪贴板图片读取依赖 uTools/Chromium 权限；失败时直接按 ⌘/Ctrl+V
- 本地路径读取仅桌面端
- 不替代 Obsidian 存量迁移，存量用 `pnpm media:migrate`
