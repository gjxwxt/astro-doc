读到一段想标记的话，和“让所有人都能看到我的评论”，其实是两件事。

## 私人标注

笔记页上的划线、批注和读后评分只存在当前浏览器。选中文字后可以标三种颜色，右侧能看到这一页的所有标注，点一下跳回原文。用 CSS Custom Highlight API 渲染，不改 DOM，复制和阅读都不受影响。

数据格式用的是 TextQuoteSelector 的思路：存原文、前后各一段上下文。这样即使文章后来改了几个字，也能尽量重新定位。

## 公开评论

公开评论用 Giscus，把评论落到 GitHub Discussions。配置在 `src/config/site.ts` 里，没填就不渲染，不会出现一个空的评论区。

## 以后要补的

如果以后要做“登录后跨设备同步标注”，再给标注加一个服务端存储和账号体系。现在没有账号，就不假装有。评论和标注将来可以共享页面位置，但存储和权限最好分开。
